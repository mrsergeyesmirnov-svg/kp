# Перенос на Selectel

Для Linux-сервера с Git, Docker Engine и Docker Compose v2.
Можно использовать существующий сервер, если на нём достаточно ресурсов.
Бот работает через long polling: домен и открытые входящие порты приложения не нужны.
Нужен исходящий HTTPS к Telegram и настроенному ИИ-провайдеру.

## 1. Подготовить папку на сервере

Под пользователем с правом запуска Docker:

```bash
git clone https://github.com/mrsergeyesmirnov-svg/kp.git kp
cd kp
mkdir -p data
chmod 700 data
```

Если папка kp уже существует, сначала проверьте её содержимое; не клонируйте поверх.
Не запускайте бота до переноса данных.

## 2. Остановить бота в Codespaces и перенести данные

В терминале, где работает бот, нажмите Ctrl+C.
Остановите также другие копии этого же бота, если запускали их.
Из папки репозитория Codespaces:

```bash
scp .env LOGIN@SERVER_IP:~/kp/.env
scp -r data/. LOGIN@SERVER_IP:~/kp/data/
```

LOGIN и SERVER_IP замените данными подключения Selectel.
При первом подключении проверьте SSH fingerprint сервера.
Команды предполагают DATA_DIR=./data в старом запуске.
Если DATA_DIR другой, копируйте содержимое именно того каталога.
В data/kp.sqlite находятся профили, шаблоны, брифы и текущие черновики.
Переносятся и файлы SQLite -wal/-shm, если они есть: поэтому копируется вся папка.
Не присылайте .env в чат и не коммитьте его в GitHub.

## 3. Запустить на сервере

Из ~/kp:

```bash
chmod 600 .env
chmod -R go-rwx data
docker compose up -d --build
docker compose ps
docker compose logs --tail=50 bot
```

Отправьте /start в Telegram, проверьте профиль и получение PDF.
Compose сохраняет базу в ~/kp/data на диске сервера, отдельно от контейнера,
и перезапускает контейнер после сбоя или перезагрузки сервера,
если запущена служба Docker. Закрытие терминала не останавливает бота.
Не запускайте вторую копию в Codespaces после переноса.

После успешной проверки можно удалить старый Codespace через интерфейс GitHub.
До проверки не удаляйте его: это резервная копия для отката.
История сообщений и уже отправленные документы в Telegram от переноса не исчезают.

## Обновить код

```bash
git pull --ff-only
docker compose up -d --build
docker compose logs --tail=50 bot
```

## Резервная копия базы

Из ~/kp на сервере, кратковременно остановив бот:

```bash
mkdir -p backups
chmod 700 backups
docker compose stop bot
tar -czf "backups/kp-data-$(date +%Y%m%d-%H%M%S).tgz" data
docker compose start bot
chmod 600 backups/*.tgz
```

Храните копию также вне сервера. Не публикуйте архивы: они содержат данные клиентов.
Для отката сначала остановите Selectel-копию, затем запускайте Codespaces-копию.
Данные, созданные после переноса, нужно вернуть отдельно.
